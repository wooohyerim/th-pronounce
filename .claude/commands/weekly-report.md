---

이번 주(지난 7일) 동안 현재 레포에서 작업한 커밋을 분석해서 노션 "주간 개발 로그" 데이터베이스에 새 항목으로 추가해줘.

절차대로 순서를 지켜서 진행해:

1. 아래 명령어로 이번 주 커밋 목록을 가져온다.
   ```
   git log --since="7 days ago" --pretty=format:"%h|%ad|%s" --date=short
   ```

2. 커밋 메시지를 보고 작업 유형을 다음 중에서 분류한다: 기능 / 버그수정 / 리팩토링 / 설정·빌드 / 문서

3. 주요 작업을 3~6개 불릿으로 요약한다. 커밋 메시지를 그대로 나열하지 말고, 의미 단위로 묶어서 한국어로 간결하게 정리한다.

4. `git remote get-url origin` 으로 저장소 주소를 확인한 뒤, 의미 있는 커밋 2~3개를 골라 아래 형식의 링크를 만든다.
   ```
   https://github.com/<owner>/<repo>/commit/<hash>
   ```

5. 노션 데이터소스 `collection://e67ab0ff-835d-4f4c-9ed4-9b91e9d906df` 에 새 페이지를 생성한다. 각 필드는 다음과 같이 채운다.
   - **주차**: `YYYY-W##` 형식 (예: 2026-W25) — 오늘 날짜 기준으로 계산
   - **기간**: 이번 주 월요일 ~ 일요일 (예: 2026-06-15 ~ 2026-06-21)
   - **커밋 수**: 1번에서 가져온 커밋 개수
   - **작업 유형**: 2번에서 분류된 태그들
   - **주요 작업**: 3번 요약 내용
   - **커밋 링크**: 4번에서 만든 링크들
   - **회고**: 커밋 메시지에서 막힌 점이나 재시도 흔적이 보이면 한 줄로 정리, 없으면 빈칸

6. 완료되면 생성된 노션 페이지 링크를 알려줘.
